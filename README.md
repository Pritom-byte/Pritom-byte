## 📊 Projects

**[Business Case Analysis](https://github.com/Pritom-byte/business-case-analysis)** — Four business decisions modelled end to end in Excel: retail store performance, a three-year EV profit model, an operating-scenario comparison and a marketing spend review. Each one ends in a recommendation, and each write-up includes what I would do differently. From *Problem Solving Using Spreadsheet Software* at FH-SWF (grade 1.7).

> Finding: normalising contribution margin by floor area reversed the store ranking — the weakest store on total margin was the strongest per square metre.

**[Retail Orders — SQL](https://github.com/Pritom-byte/retail-orders-sql)** — A four-table relational database I designed and built in Microsoft Access for my Data Management module, converted to SQLite so anyone can open it. Ten queries, from single-table filters up to three-table joins and aggregate comparisons.

> Finding: revenue per order inverts the regional ranking — but 85% of the leading region's advantage came from a single order.

**[Lotka-Volterra Ecosystem Simulation](https://github.com/Pritom-byte/ecosystem-population-dynamics-simulation)** — Seven-species extension of the predator-prey model. Coupled differential equations solved numerically with SciPy, output analysed in matplotlib. Team project at **Hochschule Rhein-Waal**, supervised by Prof. Dr. Frank Zimmer, with Dip Dutta and Kaushik Shankar Roy.

> Finding: three of the seven species go extinct within the first 15 time steps; the remaining four settle into a stable ~30-step cycle. An earlier version of the README read this wrongly — re-plotting the output is what caught it.
